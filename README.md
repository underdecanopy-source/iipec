# IIPEC Website

A modern, responsive website for IIPEC built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- 🏠 Public marketing pages (Home, About, Programs, Events, Gallery, Leadership, Blog, FAQ, Contact)
- 🔐 Secure member portal with authentication (NextAuth.js)
- 👤 Member profile management
- 📁 Member-only resources
- 📝 Blog with dynamic routing
- 📅 Event management with RSVP
- 📸 Photo gallery with lightbox
- 🙏 Prayer request submissions
- 💰 Donation support
- 🌍 i18n support (English & Yoruba)
- 📱 Fully responsive design
- ⚡ Optimized for performance and SEO

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Authentication:** NextAuth.js
- **Database:** PostgreSQL with Prisma ORM
- **Validation:** Zod
- **i18n:** next-intl
- **Hosting:** Vercel
